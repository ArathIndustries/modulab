# .claude/ — modulab's running memory

This folder is the project's running memory: a small set of files that
track where the project is, what's next, and why past decisions were made.
Humans are welcome to read it too — it's plain text, not a machine-only
format.

- **SNAPSHOT.md** — where things stand right now
- **ROADMAP.md** — what's next
- **DECISIONS.md** — an append-only log of why things are the way they are
- **VISION.md** — what this project is and why it exists
- **INDEX.md** — bookmarks back to past session summaries
- **wording-pass.md** — the vocabulary spec behind this project's app and
  doc copy (word list, HUD/Edit-drawer wording, what to remove)

An assistant picking up work here should read **SNAPSHOT.md** first.

SNAPSHOT/ROADMAP/DECISIONS/VISION/INDEX are maintained by the project
owner — treat their content as authoritative and don't rewrite it.
