# Models

## potentiometer-lever-60mm.obj

The actual 3D-printable potentiometer lever from Andrew Frueh's
[Powder Of Life](https://github.com/andrewfrueh/PowderOfLife) — the same
geometry used in his Unity digital-twin scene and printed for the physical
controller. Extracted unchanged from `Unity/PowderOfLife.unitypackage`
(`Assets/PowderOfLife/Example 3D Models/PotentiometerLever, 60mm.obj`).
